Byte 0 = opcode · Byte 1 = destination/source register (AX=0, BX=1, CX=2, DX=3) · Byte 2 = source register or high bit of the address · Byte 3 = immediate or low byte of the address. Virtual addresses are 9 bits (0x000-0x1DF). 8 instructions per 32 B page; one 8 B L1I line holds 2 instructions.

# FETCH CYCLE (common to every instruction)
T1:  MAR ← PC                         [En_PC, Ld_MAR]  (internal bus)
T2:  MMU: VPN = PC ÷ 32 → page table → frame  (page fault if P = 0)
T3:  L1I → (miss) L2 → (miss) RAM ;  MDR ← 4 bytes   [Mem_R, Ld_MDR]
T4:  IR ← MDR                         [En_MDR, Ld_IR]
T5:  PC ← PC + 4                      [Ld_PC]   → decode and execute
# MEMORY MAP
Virtual (disk): 0x000-0x1FF = 16 pages × 32 B.  Programs: code from 0x000, data with .DATA
Physical (RAM): 0x00-0xFF = 8 frames × 32 B.  Frames M0-M6 = user (paged).  M7 = pinned I/O (page 15)
Memory-mapped I/O in RAM:  0xE0-0xE7 keyboard queue (8 B)  ·  0xE8-0xEF LCD video buffer (8 B)
L2 cache: line = (PA ÷ 8) mod 4 · TAG = base PA.  L1I / L1D: one 8 B line each.
# CONTROL WORD (21 signals, in display order)
En_PC, Ld_PC, Ld_MAR, Mem_R, Mem_W, IO, Ld_MDR, En_MDR, Ld_IR, En_IR, En_ALU, Ld_AX, En_AX, Ld_BX, En_BX, Ld_CX, En_CX, Ld_DX, En_DX, En_KBD, Ld_LCD.  En_* = tri-state output enable (only one at a time); Ld_* = register load; Mem_R / Mem_W / IO = control bus.
